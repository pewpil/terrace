# terrace

A typing trainer - moving from the terminal to the web.

Built with [Nuxt](https://nuxt.com) on the latest Node LTS (see `.nvmrc`).

## Getting started

```sh
nvm use        # installs/uses the pinned Node LTS if needed
npm install
npm run dev    # http://localhost:3000
```

## Scripts

| script    | purpose                    |
| --------- | -------------------------- |
| `dev`     | dev server                 |
| `build`   | production build           |
| `preview` | serve the production build |
| `lint`    | eslint                     |
| `fmt`     | prettier write             |
| `skill`   | restore agent skills       |
